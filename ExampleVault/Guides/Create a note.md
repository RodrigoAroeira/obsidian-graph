# Create a note

Adding a note to the vault is just creating a Markdown file:

- Drop `note.md` anywhere inside the vault folder.
- Or write `[[Note name]]` in an existing note — the dangling link shows up in the graph as a missing node until the file exists.

This file lives at `Guides/Create a note.md`, but a link to [[Create a note]] finds it from anywhere in the vault, folder not required.

Related: [[Link notes]], [[Organize your vault]].
