# Link notes

Wikilinks are what become edges in the graph. The supported forms:

- Basic: `[[Start here]]`
- With alias: `[[What is Obsidian|the project itself]]`
- To a heading: `[[Link notes#Wikilinks]]`
- As an embed: `![[What is Obsidian]]`

## Wikilinks

A wikilink is a reference to a note by name. The tool resolves the name anywhere in the vault, so [[Create a note]] points at `Guides/Create a note.md` without mentioning the folder. Links inside fenced code blocks are ignored.

Folders are for organizing, not for addressing. Continue to [[Organize your vault]].
