# Start here

Welcome to **ExampleVault** — the demo vault that ships inside the **obsidian-graph** repo. It doubles as this tutorial: each note here explains a piece of the project, and the links between them are the graph you will see on screen.

## What is this place?

`obsidian-graph` is a Rust command-line tool that turns an Obsidian vault — a folder of Markdown notes connected by wikilinks — into a live, force-directed graph. This vault is exactly that: a folder of `.md` files connected by `[[wikilinks]]`.
