# What is obsidian-graph?

`obsidian-graph` is a Rust project that renders an Obsidian vault as an interactive graph.

- Your notes live in a **vault** — an ordinary folder on disk.
- Notes are **plain text**, so they stay readable and portable forever.
- Notes connect through **wikilinks** like `[[Start here]]`.
- The tool parses those links and draws the resulting **graph** in 2D or 3D.

Run it from the repo root with `cargo run --release`. Continue with [[Getting Started]] or jump straight to [[Graph view]].
